解决什么问题

WPS/PPT 的路径动画以图形中心为锚点移动，但编辑时看不到中心点，手工拖路径很难让图形精确落到目标位置。本插件让你只指定"图形中心从 A 移动到 B"，路径自动按中心精确生成。

三步用法

  1. 选中要移动的图形 —— 任务窗格自动在其中心放置 红十字 A，并在同一位置放一个可拖动的 蓝十字 B。
  2. 拖动蓝十字 B 到目标位置 —— 享受原生智能参考线/网格吸附；方向键微调，Ctrl+方向键 = 1 磅级微调；红色虚线为路径预览，坐标实时显示。
  3. 点 「生成路径动画」 —— 完成。选中图形即可看到路径：绿点=起点(图形中心)，红点=终点(B)。
要对准某个目标图形的中心？先用功能区或工具区的「中心十字」给目标图形加个红十字，再把 B 标记拖到十字上一致即可——两个十字中心重合 = 中心精确对齐。

参数说明

  • 时长：动画持续时间（秒）。
  • 触发：单击时 / 与上一动画同时 / 上一动画之后。
  • 平滑起止：默认关闭（匀速直线）；开启后有缓入缓出。
  • 替换该图形已有动画：生成前先删除该图形在主时间线上的全部动画。
  • 保留标记 / 自动开始：生成后是否保留 A/B 标记；选中新图形是否自动开始新流程。

工具按钮

  • 中心十字：给选中图形（可多选）中心加/移除红十字。
  • 清理本页标记：删除本页所有辅助标记。
  • 删除图形动画：删除选中图形的全部动画。
  • API 诊断：检测当前 WPS 版本对路径动画 API 的支持情况。

原理

图形中心 A = (Left+Width/2, Top+Height/2)（磅）。路径动画的位移坐标以图形中心为原点、以幻灯片宽/高的百分比为单位，插件把 B−A 的位移归一化后直接写入 MotionEffect.Path（"M 0 0 L dx dy E"），因此终点精确落在 B，不做视觉估计。

若生成失败，请点「API 诊断」并把结果反馈给开发者。
