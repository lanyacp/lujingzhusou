# 路径助手 · PowerPoint 版 使用说明

两种用法，选一种即可。

## 用法 A：常驻版（推荐，装一次永远在）—— 新增！

1. 双击 **`安装-常驻版.bat`**
2. 完全退出 PowerPoint → 重新打开
3. 看功能区**最上面**——「开始」选项卡左边多了一个「**路径助手**」选项卡（排在最前）→ 里面大按钮「**路径助手面板**」→ 点击弹出悬浮面板（再点收起）

> 功能区里直接放了一排常用按钮：开始、开始描迹、记一点、完成描迹、生成路径动画、清理标记，常用操作不用反复开面板。老版按钮仍保留在「加载项」选项卡里作为备用。

以后**新建、打开任何课件**，这个按钮都在，随时点开面板直接用——不会再"换个PPT就没了"。卸载：双击 `卸载.bat`。

> 首次启动若提示宏被禁用：文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置 → 选「禁用所有宏，并发出通知」→ 重开 PowerPoint → 点黄条「启用内容」。

## 用法 B：免安装工具文件（临时用/发同事）

1. **双击打开** `路径助手.pptm` → 顶部黄色条点「**启用内容/启用宏**」
2. 点封面上的「**▶ 启动路径助手**」大按钮 → 弹出悬浮控制面板
3. **保持这个文件开着**（关掉它面板就没了），去打开/新建课件 → 选中图形 → 面板「开始」→ 拖标记 → 「生成路径动画」

> 若按钮点了没反应：宏被禁用了。文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置 → 选「**禁用所有宏，并发出通知**」→ 确定 → 关闭文件重新打开 → 点顶部黄条「启用内容」→ 再点按钮。也可以按 `Alt+F8` → 运行 `ShowPanel`（能运行=宏已启用）。

## 面板功能

| 按钮 | 作用 |
|---|---|
| 形态下拉 | 直线 / 抛物线 / 圆弧 / 航点 |
| 开始(选图形) | 选中课件里的图形后点它：中心出现红十字 A（直线形态另有蓝十字 B） |
| 中心十字 | 给选中图形中心加/移除红十字（也是吸附目标） |
| 放C点 / 放D点 | 标记点对齐：C 放移动图形的参照点（如顶点），D 放目标（**先点选目标图形再点「放D点」会直接落在其中心**） |
| 放P/M点 | 抛物线顶点 P / 圆弧弧点 M |
| +航点 / 清空航点 | 航点形态：逐点放置（先点选图形再加=落其中心） |
| 开始描迹 / 记一点 / 完成描迹 | 描迹形态：形态下拉选「描迹」→ 点「开始」→ 点「开始描迹」→ **拖动洋红十字沿曲线走，每拖一段松手会自动记点**（也可点「记一点」手动补）→ 走完点「完成描迹」→ 点「生成路径动画」。中途可再点「开始描迹」从末点接着描 |
| 时长/触发 | 时长秒数；触发只作用于首段，后续段自动"上一动画之后"接力 |
| 平滑曲线 | 航点间圆滑过渡（Catmull-Rom） |
| 替换旧动画 | 生成前删除该图形已有动画 |
| 生成路径动画 | 按当前标记生成；**12pt 内自动吸附最近图形/红十字中心**（结果里会提示） |
| 清理标记 | 删除全文档所有辅助标记 |

## 与 WPS 版的差异

- **曲线 = 多段直线接力**：PowerPoint 宏只能写直线位移，抛物线/圆弧/航点由多段小直线拼接（动画窗格里会看到多段，属正常）；段间自动"之后"触发，播放连贯
- **吸附在生成时进行**（不是拖动时实时吸），效果一致
- 描迹靠"拖动标记+松手自动记点"实现，记下的点会自动做滑动平均平滑；点密一点更贴近手绘曲线

## 常见问题

- **没有"启用内容"黄条、宏跑不了**：文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置 → 选"禁用所有宏并发出通知"，重新打开文件即可出现黄条
- **生成报错**：确认流程顺序（选图形→开始→放标记→生成）；面板底部有状态提示
- **关掉面板后想再开**：回到工具文件点启动按钮，或 Alt+F8 → ShowPanel
