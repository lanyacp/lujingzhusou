# 路径助手 · PowerPoint 版 使用说明

两种用法，按需要选。**推荐方法二**（常驻面板，功能全）；不想装就用方法一。

---

## 方法二：常驻面板版（功能最全，推荐）

**装一次，永久在。** 三步：

1. **完全退出 PowerPoint**（开着的话文件被占用，装不上；安装脚本检测到会提示你先退出）；
2. 双击 **`安装-常驻版.bat`**；
3. 重新打开 PowerPoint。

顶部（功能区下方）会多出一个「**路径助手面板**」按钮，点它即弹出**悬浮面板**（不挡操作），对**任何**课件都有效。

面板功能：
- 形态下拉：直线 / 抛物线 / 圆弧 / 航点 / 描迹
- 开始(选图形) · 中心十字 · 放 C/D/P 点 · +航点 · 清空航点
- 时长 · 触发 · 平滑曲线 · 保留标记 · 替换旧动画
- 生成路径动画 · 清理标记 · 关闭面板

小建议：**「替换旧动画」平时勾上**——同一个图形重新生成时，自动删掉它上一条路径，不会越叠越多。

**免安装备选**：直接双击 `路径助手.pptm` → 启用宏 → 点封面「▶ 启动路径助手」。保持它开着即可对任何课件操作，功能一样。

**卸载**：先完全退出 PowerPoint，再双击 `卸载.bat`。

---

## 方法一：简易宏（零安装，最轻量）

文件：`路径助手-简易宏.bas`

1. 打开课件（.pptm/.pptx）→ `Alt+F11` → 「文件 → 导入文件」选它（或插入模块后整段粘贴）
2. 回幻灯片：点选"要移动的图形"，再 **Ctrl+点**"目标图形"
3. `Alt+F8` → 运行 `精确路径_中心到中心`
4. 弹出确认框：**是**＝按框里写的方向生成；**否**＝对调方向；**取消**＝不做

其他宏：`精确路径_到坐标`（选 1 个图形，输入目标坐标）、`删除本图形动画`。

> 不依赖加载项/窗体，适合只想要"中心到中心"、或临时在别人电脑上救急。
> 生成好的动画是 PowerPoint 标准动画，换电脑播放不需要这个宏。

## 与 WPS 版的差异

- **曲线 = 一条完整路径**：抛物线/圆弧/航点/描迹在动画窗格里只占**一个**动画条，路径上的点由程序按公式算好
- **吸附在生成时进行**：蓝十字拖到目标附近（不用精确对位），点「生成」时自动吸到最近的图形中心
- **拐弯的路线用「航点」**：一条路线依次经过所有航点；不勾「平滑曲线」走直角，勾上则圆滑
- 描迹：「开始描迹」后拖一段、松手自动记一点，也可点「记一点」手动补

## 常见问题

- **装完没看到「路径助手面板」按钮**：确认安装时 PowerPoint 已完全退出，装完重新打开过。还是没有，就用上面的免安装版 `路径助手.pptm`，功能一样
- **点了按钮没弹面板**：`Alt+F8` 手动运行 `ShowPanel` 或 `TogglePanel`
- **出现"已禁用宏"的黄色提示**：点「启用内容」；或 文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置 → 选"禁用所有宏并发出通知"
- **辅助标记会留在课件里吗**：默认不会，生成后自动清理；只有勾了「保留标记」才会留着，点「清理标记」即可
