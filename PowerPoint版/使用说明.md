# 路径助手 · PowerPoint 版 使用说明

两种用法，都能用。**推荐装方法二**（常驻面板，功能全）；不想装就用方法一。

---

## 方法二：常驻面板版（功能最全，推荐）

**装一次，永久在。** 双击 **`安装-常驻版.bat`** → 完全退出 PowerPoint → 重新打开：

- 顶部功能区出现「**路径助手**」选项卡；
- 或常驻工具条上的「**路径助手面板**」按钮。

点一下即弹出**悬浮面板**（无模式，不挡操作），对**任何**课件都有效。

面板功能：
- 形态下拉：直线 / 抛物线 / 圆弧 / 航点 / 描迹
- 开始(选图形) · 中心十字 · 放 C/D/P 点 · +航点 · 清空航点
- 时长 · 触发 · 平滑曲线 · 保留标记 · 替换旧动画
- 生成路径动画 · 清理标记 · 关闭面板

**免安装备选**：直接双击 `路径助手.pptm` → 启用宏 → 点封面「▶ 启动路径助手」。保持它开着即可对任何课件操作。

**卸载**：双击 `卸载.bat`，重启 PowerPoint。

---

## 方法一：简易宏（零安装，最轻量）

文件：`路径助手-简易宏.bas`

1. 打开课件（.pptm/.pptx）→ `Alt+F11` → 「文件 → 导入文件」选它（或插入模块后整段粘贴）
2. 回幻灯片：**先点"要移动的图形"，再 Ctrl+点"目标图形"**
3. `Alt+F8` → 运行 `精确路径_中心到中心` → 完成（前者中心精确移到后者中心）

其他宏：`精确路径_到坐标`（选 1 个图形，输入目标坐标）、`删除本图形动画`。

> 不依赖加载项/窗体/Ribbon，适合只想要"中心到中心"、或临时在别人电脑上救急。

---

## 与 WPS 版的差异

- **曲线 = 多段直线接力**：PowerPoint 宏只能写直线位移，抛物线/圆弧/航点由多段小直线拼接（动画窗格里看到多段属正常），段间自动"之后"接力
- **吸附在生成时进行**（不是拖动时实时吸），效果一致
- 描迹：面板版用「开始描迹 → 拖一段松手 → 自动记点 → 完成」

## 常见问题

- **没有"启用内容"黄条、宏跑不了**：文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置 → 选"禁用所有宏并发出通知"，重开文件后点黄条"启用内容"
- **装完看不到选项卡/按钮**：确认**完全退出**过 PowerPoint（任务管理器里没有 POWERPNT 进程）再重开
- **点按钮没弹面板**：`Alt+F8` 手动运行 `ShowPanel` 或 `TogglePanel` 即可弹出
