# 路径助手 · PowerPoint 版 使用说明

## 方法一：简易宏（现在就能用，最稳，无需加载项/窗体）

文件：`路径助手-简易宏.bas`

1. 打开你的课件（.pptm 或 .pptx）
2. `Alt+F11` 打开 VBA 编辑器 → 菜单「文件 → 导入文件」选 `路径助手-简易宏.bas`
   （或 插入→模块，把文件内容整段粘贴进去）
3. 回幻灯片，**按顺序选两个图形**：先点"要移动的图形"，再 **Ctrl+点**"目标图形"
4. `Alt+F8` → 运行 `精确路径_中心到中心` → 完成（从前者中心精确移到后者中心）

其他宏：`精确路径_到坐标`（选 1 个图形，输入目标坐标）、`删除本图形动画`。

> 这个宏不依赖窗体/加载项/Ribbon，不会编译报错，适合应急或只要"中心到中心"的场景。

## 方法二：完整面板版（加载项，功能最全）

> 说明：当前已部署的加载项因窗体命名问题会弹"编译错误"，**源码已修复**；
> 需**重启电脑**（恢复 PowerPoint 组件服务）后用 `tools/build-ppt.ps1` 重新生成才会正常。
> 在此之前，请用上面的方法一。

修复后用法：

1. 双击 **`安装-常驻版.bat`**
2. 完全退出 PowerPoint → 重新打开
3. 点功能区「**加载项**」选项卡 →「**路径助手面板**」→ 弹出悬浮面板

面板功能：形态下拉（直线/抛物线/圆弧/航点/描迹）、开始(选图形)、中心十字、放C/D/P点、+航点、时长/触发、替换旧动画、生成路径动画、清理标记。

> 免安装备选：直接双击 `路径助手.pptm` → 启用宏 → 点封面「▶ 启动路径助手」。保持它开着即可对任何课件操作。

## 与 WPS 版的差异

- **曲线 = 多段直线接力**：PowerPoint 宏只能写直线位移，抛物线/圆弧/航点由多段小直线拼接（动画窗格里看到多段属正常），段间自动"之后"接力
- **吸附在生成时进行**（不是拖动时实时吸），效果一致
- 描迹：面板版用「开始描迹→拖一段松手→自动记点」；简易宏版暂未含描迹（用航点逐点替代）

## 常见问题

- **没有"启用内容"黄条、宏跑不了**：文件→选项→信任中心→信任中心设置→宏设置→选"禁用所有宏并发出通知"，重开文件
- **点按钮弹"编译错误 modPathHelper"**：说明是修复前的旧加载项，改用方法一，或重启电脑后重装
- **卸载常驻版**：双击 `卸载.bat`，重启 PowerPoint
