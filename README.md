# 路径助手 — WPS 演示「精准路径动画」加载项

## 解决什么问题

WPS/PPT 的路径动画以**图形中心**为锚点移动，但编辑时看不到中心点，手工拖路径很难让图形精确落到目标位置。

本插件让你只指定「图形中心从 **A** 移动到 **B**」：

1. 选中要移动的图形 → 插件自动在其中心放 **红十字 A**，并放一个可拖动的 **蓝十字 B**
2. 拖动蓝十字 B 到目标位置（原生智能参考线/网格吸附，方向键微调，Ctrl+方向键 = 1 磅级）
3. 点「生成路径动画」→ 路径按图形中心精确生成：**绿点=起点(中心)，红点=终点(B)**

## 安装

### 方式一：install.bat（推荐，免构建）

1. 双击 `install.bat`
2. **完全退出 WPS**（包括托盘图标和后台进程），重新打开 WPS 演示
3. 功能区出现「**路径助手**」选项卡即成功

### 方式二：手动安装

1. 把 `index.html`、`main.js`、`ribbon.xml`、`js/`、`ui/`、`images/` 复制到
   `%APPDATA%\kingsoft\wps\jsaddons\ABPathHelper_1.0.0\`
2. 在 `%APPDATA%\kingsoft\wps\jsaddons\publish.xml` 中**合并**写入一行（保留已有其他加载项的条目）：
   ```xml
   <jsplugins>
     <jsplugin name="ABPathHelper" type="wpp" url="ABPathHelper_1.0.0" version="1.0.0" enable="enable_dev" install="null"/>
   </jsplugins>
   ```
3. 重启 WPS。

### 方式三：wpsjs CLI 调试（热更新，需 Node.js）

```bash
npm install -g wpsjs
cd 本目录
wpsjs debug        # 在 jsplugins 调试模式下加载（新版个人版可用）
```

## 卸载

双击 `uninstall.bat`，重启 WPS。

## 工作原理

```
A = 图形中心 = (Left + Width/2, Top + Height/2)        单位: 磅
B = 蓝十字标记中心（拖拽定位）
dx = (B.x − A.x) / 幻灯片宽度     dy = (B.y − A.y) / 幻灯片高度
```

路径动画的位移坐标以图形中心为原点、以幻灯片宽/高的百分比为单位。插件把归一化位移直接写入 `MotionEffect.Path`（`"M 0 0 L dx dy E"`），因此终点精确落在 B 点，不做视觉估计。

### 动画创建策略（自动降级 + 回读校验）

| 策略 | 做法 | 说明 |
|---|---|---|
| 1 | `AddEffect(msoAnimEffectPathRight)` 打底 → 改写 `MotionEffect.Path` | 实测可用（首选），写入后重新走链回读校验 |
| 2 | `AddEffect(msoAnimEffectCustom)` → `Behaviors.Add(msoAnimTypeMotion)` → 对新增行为写 `Path` | 兜底 |

> 实测说明（2026-11，WPS COM 层自动化验证，文件级 XML 已确认）：
> - `MotionEffect.Path` 可读可写，是 WPS 里唯一可靠的路径写入方式
> - `MotionEffect.FromX/ToX` 写入会被**静默忽略**（回读恒为默认值），因此不作为策略
> - 时间线每次变更后 Sequence/Effect 引用会失效，插件在每次操作前都重新获取引用

## 功能清单

- **创建路径**：任务窗格，A/B 标记 + 虚线预览 + 实时坐标（磅/厘米/幻灯片百分比）
- **五种路径形态**（任务窗格「形态」下拉）：
  - **直线**：中心→B 或 C→D 标记点对齐
  - **抛物线**：锚点→终点 D，曲线精确经过顶点 P（平抛/斜抛教学）
  - **圆弧**：锚点→终点 D，沿经过弧点 M 的圆弧（三点定圆，半径误差 ≤0.03pt）
  - **航点**：N 个可拖航点按序经过，可勾选「平滑」(Catmull-Rom 圆滑)
  - **描迹**：先手绘参照曲线，点「开始描迹」后拖洋红标记沿曲线走一遍（停住 1.6 秒自动完成），笔尖等图形锚点精确复现你的轨迹
- **自动吸附**：拖动 B/C/D 标记到任意**图形**或**中心红十字** 12 磅范围内松手，自动吸附到其中心精确重合（自动排除移动图形自身与插件标记；可勾选开关）
- **标记点 C→D 模式**：在移动图形上任选参照点 C（如三角形顶点），目标处选点 D（可吸附到目标中心红十字），生成后 C 精确落在 D 上——支持"顶点对顶点/顶点对中心"等非中心对齐场景
- **中心十字**：给任意选中图形（可多选）的中心加/移除红十字——直接解决"看不见中心"的痛点，也是吸附目标
- **参数**：时长 / 触发方式 / 平滑起止 / 替换已有动画 / 保留标记
- **清理标记**：本页或整个文稿（所有辅助形状以 `__pthlp_` 前缀命名，可安全识别）
- **删除图形动画**：删除选中图形在主时间线的全部动画
- **API 诊断**：检测当前 WPS 版本对动画 API 的支持情况（临时图形+动画，自动清理）

### 标记点模式与吸附用法

1. 流程中点「放C点」→ 绿十字出现在移动图形中心 → 拖到参照位置（如顶点，可放大视图精放）
2. 点「放D点」→ 橙十字 → 拖到目标处（拖近中心红十字松手即自动吸附重合）
3. C、D 齐备后自动进入标记点模式（B 标记移除），点「生成路径动画」→ 播放时 C 点精确落在 D 点
4. 「清除标记点」恢复默认的中心→B 模式；微调标记时若不想被吸附，取消勾选「拖近红十字自动吸附」

### 行为细节

- 生成后插件会自动选中该图形（方便查看路径），此时**不会**自动重启流程；重新点选图形即可开始下一轮
- 流程中切到**其他幻灯片**的图形：自动清理旧页的 A/B 标记，在新页开始
- 切换到**其他演示文稿**：流程自动重置（旧文档里残留的标记可在该文档中用「清理标记」移除）
- 功能区「清理标记」会联动停止任务窗格中的流程，避免标记被立即重建

`probe/wps-macro-probe.js` 可直接粘进 WPS 的 JS 宏编辑器运行（工具 → 开发工具 → JS宏），
验证你的 WPS 版本是否支持路径动画 API，与本插件使用同一套调用链。

## 故障排查

**安装后功能区没有「路径助手」选项卡**
- 确认 WPS 完全退出后重启（任务管理器里结束所有 wps.exe / wpp.exe）
- 检查 `%APPDATA%\kingsoft\wps\jsaddons\publish.xml` 中是否有本加载项条目，且没有破坏 XML 结构
- 部分 WPS 版本对 `enable` 属性取值敏感：把 `enable="enable_dev"` 改成 `enable="enable"` 再重启试试
- **WPS 自动更新后插件不加载**：WPS 会在后台自动升级版本（`%LOCALAPPDATA%\Kingsoft\WPS Office\<版本号>\utility\install.ini` 里的 `[update]` 段可确认）。更新后首次启动请人工打开一次 WPS 并点完所有首次运行提示框（隐私协议/默认软件等），这些对话框会阻塞加载项加载；之后再重启一次 WPS
- **信任文件**：`%APPDATA%\kingsoft\wps\jsaddons\authaddin.json` 和 `jsaddinblockhost.ini` 是 WPS 自动生成的机器信任记录（含文件指纹）。若反复改文件后插件不加载，可把这两个文件备份后删除再重启 WPS；`jsaddinblockhost.ini` 若记录了本插件（反复强杀 WPS 可能触发崩溃保护拉黑），删除后重启即可解除
- 企业版可能禁用了 JS 加载项（策略管控），此时可用 `wpsjs debug` 调试模式，或用 probe 宏脚本替代

**生成路径动画失败**
- 点任务窗格的「API 诊断」，按报告判断是哪个环节不支持（报告含 AddEffect 每种调用形式的具体报错）
- WPS 版本更新可能改变 JS 桥接对 API 参数的封送行为（如枚举值需用 `Application.Enum` 对象而非数字）——插件已内置多种调用形式自动尝试
- 把诊断结果 + WPS 版本号（文件 → 帮助 → 关于）反馈给开发者
- 也可用 `probe/wps-macro-probe.js` 粘贴到 WPS 的 JS 宏编辑器（工具 → 开发工具 → JS宏）直接运行验证

**B 标记被我删掉了**
- 插件会在轮询时自动在图形中心重建一个，重新拖即可。

**中心十字不跟随图形移动**
- 中心十字是静态参照物，图形移动后再次点击「中心十字」刷新（或先移除再加）。

## 目录结构

```
index.html / main.js / ribbon.xml   加载项入口与功能区定义
js/enums.js   数值枚举常量（不依赖 wps.Enum 命名）
js/core.js    核心逻辑：上下文/选择/标记/预览线/三级策略链/诊断
js/ribbon.js  功能区回调与任务窗格管理
js/taskpane.js 任务窗格状态机（由 ui/taskpane.html 引入）
ui/           任务窗格与帮助页
images/       功能区图标
probe/        JS 宏验证脚本（免安装）
tools/        publish.xml 合并脚本 / COM 自动化测试
```

## 已知限制

- 仅支持 WPS 演示（WPP）；MS PowerPoint 请参考 `js/core.js` 的策略链自行移植 VBA 版本（对象模型同构）。用它做好的课件是标准格式，拷到 PowerPoint 上动画照常播放
- 组内子形状会自动提升为顶层组合图形来做动画
- 抛物线 / 圆弧 / 平滑航点 / 描迹等曲线与多段路径，依赖 `MotionEffect.Path` 的 M/L/C/Z 语法；个别 WPS 版本对贝塞尔段支持有差异，生成后建议播放确认
- 安装目录名 `ABPathHelper_1.0.0` 是 WPS 的加载项注册 ID，与软件版本号（v1.3.2）不是一回事，不要手改
